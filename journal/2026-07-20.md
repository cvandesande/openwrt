### 2026-07-20, twelfth session — sysupgrade metadata bug fixed, policy r6+r7

**sysupgrade metadata bug root-caused and fixed (issue #12).** The image recipe
had the pipeline order wrong: `append-metadata` ran on the *uncompressed*
image, then the generic ext4 `GZ_SUFFIX` rule in `include/image.mk` gzipped the
whole file, burying the fwtool trailer *inside* the gzip stream. Not an
upstream bug. x86 gets it right — compress first, append after. `mono_gateway-dk`
is the ONLY layerscape device with `FILESYSTEMS := ext4`, which is why nobody
upstream hit it. Fixed in `c879085263`; naming the image `*.gz` suppresses the
double-gzip (`%gz` filter in `Device/Build/image`), the output filename is
unchanged so the release workflow needed no edit, and `append-metadata` running
last means the sha256sum/signature cover the artifact actually shipped.
Validated in production with plain `sysupgrade`, no `-F`. Verification recipe
is in the build/flash gotchas below.

**selinux-policy r6 and r7 shipped and pushed** (`mono-ask-25.12` `064e4f0294`,
`mono-ask` `09c07ee3d9`).

- r6 (`783fc6dab6`): `xtables` gained `.locales.client.type`
  (iptables-save/ip6tables-save walk /usr/share/locale; r5 gave logread the
  equivalent and missed xtables), and `cgiio` gained
  `.sys.agent.exec.auditexecuteaccess_all_files` — cgi-exec `stat()`s a binary
  before exec'ing it, so **r5's type_transition alone never worked**, failing
  with EACCES before any transition could occur.
- r7: **hotplug locktmp** — `manage_file_files` + `readwrite_file_dirs`; the
  previous pair only allowed using an EXISTING lock, and /tmp/lock is tmpfs so
  it must be created each boot (mirrors envtools/odhcpd). **mwan3 domain** —
  patch 012 previously defined only a runtmp file type, no subject domain and
  no exec filecon, so `/usr/sbin/mwan3` stayed generic `exec.file` and confined
  cgi-exec could not even getattr it; **the mwan3 LuCI pages had never worked
  under enforcing**. Added following the boarddetect/hotplug-call pattern for
  SCRIPT agents (`.shell.client.type` for the `#!/bin/sh` interpreter,
  functions/libubox for sourced libs, `subj_type_transition` per helper).
  **swanmon + strongswan** — same shape; the `strongswan` block types ONLY
  `/tmp/run/charon.vici`, leaving charon unconfined, using the trick that **an
  unconfined creator still produces correctly-labelled files via a
  type_transition from `file.unconfined`**. Modelled on `nlbwmonsysagent.cil`.
  Both LuCI pages confirmed working enforcing.

**Pattern now established** for any other LuCI helper that turns out to be
generic `exec.file`: label the binary, add a domain, add the `cgiio`
transition.

**Method note that keeps paying off:** a denial fixed often reveals a SECOND
behind it, because enforcing stops at the first. The r7 locktmp fix worked and
immediately exposed the runtmp mkdir denial. Never read "the denial is gone" as
"the path works".

**Live-relabelled vs flashed asymmetry:** the router runs binaries relabelled
by `restorecon` after `load_policy`. A fresh flash applies filecons from the
image instead. If behaviour differs after a flash, suspect that first.
