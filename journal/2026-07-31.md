## Decisions

- **Retire the meta workspace.** Its original purpose was convenient access to
  the `ASK/` and `OpenWRT-ASK/` reference trees; its surviving purpose is
  multi-repo code intelligence over the four *owned* repos, which the reference
  trees are not even part of. Code intelligence needs `--root <directory>`, not
  a tracked meta-repo, so a plain sibling layout satisfies it.
- **`lab-snapshots/` and `openwrt-backup/` do not matter** and will not be
  migrated (user, this session). Not deleted — the wipe does that for free.
- **Journals become append-only, one file per session date.** `HANDOFF.md` was
  serving two consumers with opposite needs: a fresh session wanting ~20 lines
  of current state, and archaeology wanting a complete record. The
  consolidate-never-drop rule and its `PostToolUse` hook existed only because a
  single rewritable file had to do both. Splitting them retires that discipline
  entirely.

- **`mono-ask` is the home** for `STATE.md`, `journal/`, docs, and scripts. The
  `docs/05-*` / `docs/06-*` skew stands — those remain `mono-ask` only.
- **Agent instructions consolidated** into one `AGENTS.md` here (192 → 195

  Claude Code reads `CLAUDE.md`, not `AGENTS.md`, so the rules had not been

  convention. `mono-status-all.sh` was rewritten to take `--project-root` and
  skip absent repos, so it works in a clone of this repo alone.
- **`docs/project-map.md` dropped as superseded.** Its branch model listed the
  nonexistent `*-next` branches and omitted the `-25.12` line, and its SELinux

  `AGENTS.md`. Third instance of the same rot after `NOTES.md` and the `*-next`
